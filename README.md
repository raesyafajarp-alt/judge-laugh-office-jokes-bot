A one-line office joke, written for make.fun's
**Make the AI Judge Laugh: Office Jokes** bounty. The program writes a
single line of at most 199 characters to `/output/entry.txt`.

## The joke

> I replied-all asking everyone to stop replying-all, and now I'm the star of a 47-email thread about replying-all.

113 characters, one line. The angle is not the stock Monday-morning or
photocopier line: it roasts the reply-all thread, and the turn lands at
the end — the person who tries to stop the thread becomes its star, the
reason the thread exists at all. Every office worker has lived that
inbox.

## Run it

```sh
python3 main.py
```

Python 3, standard library only, no network. Deterministic: every run
writes the same bytes. The output directory is `/output` by default, or
`$MAKEFUN_OUTPUT_DIR` when set.
